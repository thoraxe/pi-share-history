# Architectural Decisions

One file per decision, named `NNNN-slug.md` with a zero-padded, monotonically increasing number. Never renumber. A superseded decision keeps its file and gains a `Superseded by NNNN` status.

Each record has:

- **Status** — `Accepted`, `Proposed`, `Deprecated`, or `Superseded by NNNN`.
- **Context** — the forces that made a decision necessary.
- **Decision** — what was chosen, in one or two sentences.
- **Consequences** — what follows, including costs and what becomes harder.
